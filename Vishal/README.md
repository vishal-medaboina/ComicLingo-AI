# ComicLingo AI — Learn English. Live the Story.

**ComicLingo AI** is an adaptive, Generative-AI English-learning platform where learners acquire real-world conversational English through original, multi-panel interactive comic stories, animated characters, and story-driven practice.

### Additional Accessible Features:
- **AI Character Studio**: Natural-language character creator with copyright safeguards, animated preview stage, gestures & emotions, and multi-character interaction.
- **My Comics**: Library of all generated comic stories with cover previews and quick resumption.
- **Vocabulary Bank**: Interactive vocabulary storage with definition, phonetic audio pronunciation via Web Speech API, and flashcard review mode.
- **Achievements & Badges**: Gamification badges celebrating reading streaks, vocabulary exploration, and quiz performance.
- **Profile & Settings**: Learner age adaptation (5–10, 10–15, 15+), English level selection, speech rate, and sound controls.
- **Landing Page Overview**: Comprehensive product landing page with value proposition and interactive comic demo.

## 🛠️ Key Technical Highlights
- **Vite 5 + React 18 + TypeScript + Tailwind CSS**: Responsive, type-safe architecture.
- **Context-Aware Emotional Acting Engine**: Characters automatically change facial expressions (eyes, mouth, eyebrows) and body language based on dialogue context.
- **Multi-Panel Comic Generation**: 2, 3, 4, 5, and 6-panel layouts with varied composition, sound effects (SFX), and speech bubbles.
- **Web Speech API Audio Narration**: Spoken dialogue and vocabulary pronunciation with native English TTS voices.
- **Zero Paid API Requirement (Offline Sandbox Mode)**: Built-in generative simulation engine that produces unlimited personalized stories and characters without external API costs or setup friction.
